## 2. 关键行为与实现保障

### 首页与异常

- 正常首页不出现“最后同步 / 数据截至 / 缓存时间 / 队列阶段”。
- 恢复缺测仍在恢复业务内容中表达，不被当成全局连接故障。
- 背景错误保留在诊断中；训练列表和编辑动作各有就地错误说明。
- 部分接口失败不清空成功模块；今日建议是否可确认单独判断。
- 用户主动取消、后台尚未完成和真正成功不共用“成功”文案。
- 删除全局错误 sheet 并不删除错误数据；计划保存、锁定、反馈仍显示操作结果。

### 训练反馈

- 新增 `workout_override_revision_conflict`；版本检查在写入事务内完成。
- `/v1/commands` 的 202 只是接受请求，不会被当成已经保存。
- 幂等键和业务 effect/receipt 同事务机制继续复用现有命令队列。
- 原生保存前将本次命令放入按服务/用户/datasetEpoch 隔离的受保护缓存；响应丢失继续使用同一个命令。
- 已有不确定提交再次遇到认证/请求错误，不能据此断言之前未保存并丢掉原命令。
- 新提交在入队前被明确拒绝时，允许重新编辑；真正执行冲突保留表单输入。
- 用户可查看最新记录，再明确选择“放弃当前输入，使用最新记录重新编辑”。不会自动把旧草稿覆盖到新 revision。
- 保存成功、分析任务失败、显示刷新失败分开反馈；不把重算失败误报为未保存。
- Web 重试保留同一请求对象，待确认期间冻结提交内容；关闭窗口不会撤销已提交任务。

### CSV 导出

- 新接口：`GET /v1/exports/workout-summary?from=YYYY-MM-DD&through=YYYY-MM-DD`。
- 必须配置服务端 API Token 并携带正确 Bearer；不在匿名读取白名单中，响应 `Cache-Control: no-store`。
- 单次最多 366 个自然日、2000 条已分析训练；超量明确拒绝，不静默截断。
- 日期按 Asia/Shanghai 解释，开始日包含、结束日完整包含；iOS 日期控件也使用该时区。
- 查询行与总数使用单个只读事务，避免导出期间切换 active 结果造成不一致。
- 仅投影五项列：开始时间、类型、距离、时长、平均配速。不是 Apple Health 全量导出，也不是系统备份。
- CSV 对公式型文本做前缀转义，对引号/换行进行 CSV 编码；不把任意备注拼入分享内容。
- Web 下载使用本地 Blob 并回收 URL；原生使用系统文件导出器，不创建公开下载地址。
- 新 Web 导出入口仅在 ≥1024px 可见，没有改动冻结的窄屏媒体查询或导航。

### 训练提醒

- 只有用户主动开启时才请求通知权限；默认启动不会弹授权请求。
- 只安排未来七天中的可执行、非休息且未观察到训练的日期。
- 使用一次性通知，不使用永久循环；计划更新、完成日期改变、连接身份变化和关闭提醒时重核并清理旧通知。
- 异步回调带 generation 所有权检查；旧任务不能把新配置覆盖回去。
- 提醒正文不包含健康数值、路线或成绩，要求打开 App 查看最新安排。
- 拒绝权限不影响其他功能；App 内提供系统设置入口。

## 3. 明确的兼容性与限制

1. **旧客户端窗口**：expectedRevision 暂为可选，未升级客户端仍有覆盖风险。新版两端受保护，不宣称所有历史版本都已实现冲突检测。后续确认无旧客户端后，才能收紧为必填。
2. **没有离线业务写队列**：离线可编辑当前表单，但不会偷偷提交或显示已保存。尚未点保存的草稿不承诺跨进程持久化。
3. **缓存不是业务数据库**：原生 pending 命令缓存可能被清理/淘汰。其第二道保护是 expectedRevision，避免再次追加同一旧版本；这不等于承诺清缓存后仍能找回原操作凭据。
4. **Web 页面关闭**：不确定请求保留在当前组件会话中，未新增浏览器健康备注持久化。重开后应读取最新记录；CAS 防止旧版本覆盖，但不承诺浏览器崩溃后的原请求自动追踪。
5. **提醒不是实时推送**：App 关闭后在另一端修改计划，已排好的本地提醒无法即时撤回；下次 App 运行核对时清理。通知也不能保证准点送达。
6. **完整完成回执未引入**：用户确认整份处方完成、漏课评级、依从性打分仍不在本次范围。已有跑步不是逐段处方完成的证明。
7. **导出范围**：CSV 仅包含已分析训练；PDF、GPX、健康全量备份及分享公开链接仍按方案后置。
8. **生产配置未改动**：未修改云机匿名读取设置、TLS、资源限制、备份排程，未执行迁移、重启或恢复。工具检查不等于生产验收完成。
9. **未承诺算法准确性**：未重写手机评分/预测，自动化测试不能代替预测有效性评估。
