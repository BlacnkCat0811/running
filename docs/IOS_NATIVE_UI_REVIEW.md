## 已修复

| 优先级 | 问题 | 修复 |
| --- | --- | --- |
| P1 | 连接地址逐字写入当前会话，首次设置可能中途跳页；设置编辑会触发缓存切换 | 地址、Token 使用草稿，点击连接后才应用；选择发现的服务只填草稿；切换草稿地址重新读取该地址的 Token，不沿用其他服务凭证 |
| P1 | 旧服务的异步读取/写入响应可能更新新服务页面和缓存 | 连接/刷新/写入校验配置版本、URL 和 Token；列表与详情额外校验请求标识与缓存范围 |
| P1 | 快速切换训练筛选时，慢请求覆盖当前筛选；无缓存时保留上一筛选结果 | 请求标识隔离；切换筛选清空旧结果并读取对应缓存；分页使用独立加载状态 |
| P1 | 训练详情与上一条训练时序混用，失败后无限加载，重入详情无法重试 | 同步切换详情和时序缓存；丢弃过期响应；提供错误、重试和下拉刷新；取消不弹失败 |
| P1 | 计划页隐藏导航栏，缺少明确返回入口 | 恢复原生导航栏及返回按钮 |
| P1 | 锁课可连续触发，写成功但后续刷新失败被误报为锁课失败 | 模型级防重入、按钮忙碌状态；区分写入确认与刷新失败 |
| P2 | 每日距离输入每个字符都转 Double，导致小数中间态丢失 | 独立字符串草稿，保存时转换；验证每日 0–80 km，留空为未设置，与服务端范围一致 |
| P2 | 全页刷新把训练列表失败误标为在线 | 列表返回成功状态，完整刷新保留失败状态 |
| P2 | 部分按钮点击区域小，忙碌按钮仍可点击，同步显示虚假的 55% | 图标和分段按钮最小高度 44pt；公共忙碌按钮禁用；同步改为不定进度指示器 |
| P2 | 前台观察器同步成功后原生页面未及时刷新 | 观察 HealthKit 数据更新代数并刷新原生数据 |
