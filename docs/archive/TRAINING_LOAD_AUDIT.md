# RAI 训练负荷 V2 脱敏验收报告

> 评估日期：2026-07-13  
> Active Feature：`workout-feature-v2`  
> Active 负荷算法：`training-load-config-v2`

## 1. V2 变化

- Apple Health 区间型心率按训练窗口裁剪和真实持续时间积分。
- 心率与速度均值、方差改为区间时长加权。
- 心率覆盖率改为区间并集，不再使用首条到末条的跨度。
- 序列覆盖达到 70% 时，观测负荷归一化到完整训练时长，置信度仍受覆盖率约束。
- 平均配速明显不合理的训练默认隔离；用户明确选择“计入运动统计”后可恢复。
