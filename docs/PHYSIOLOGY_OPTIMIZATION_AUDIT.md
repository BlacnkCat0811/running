## 目标与结论

本轮目标是加入乳酸阈值、最大摄氧量、5K/10K/半马预测，并提高数据分析与预测准确性，在证据充分时引入机器学习。

当前实现已经形成完整的“健康证据 → 生理估计 → 有效表现能力 → 专项准备度 → 比赛场景 → 预测区间 → walk-forward 验证 → 受控 ML”链路。机器学习不是默认开启；只有真实持出数据证明优于公式基线时才激活。

## 准确性保护

- 每次预测和回测只读取目标时刻之前的数据；
- 普通训练只作为低权重表现包络，不冒充比赛；
- VO₂max 不能直接替代有效 VDOT；
- 环境、爬升、恢复、专项准备度分别建模并保留独立修正秒数；
- 预测输出乐观/保守区间和证据代码，不只输出单点；
- 同距离至少 3 个历史结果才允许偏差校准；
- Ridge 必须通过 walk-forward 持出门槛，任一距离退化超过 5% 即拒绝；
- 所有 ML 修正限制在原预测的 ±12%。
