# 运动深色视觉合同

现有原生 iOS 只有一套运动深色视觉；源文件为[TechViews](../RAI/Skins/Technology/TechViews.swift)、[TechTheme](../RAI/Skins/Technology/TechTheme.swift)与[圆角表面组件](../RAI/Skins/Technology/TechSurfaceStyle.swift)。`Technology` / `Tech`、`paper` / `cyan` 等名称沿用代码路径与语义映射，不代表另一套可选择皮肤。
界面入口见[iOS README](../README.md)，历史视觉文件说明见[设计索引](README.md)。不以旧截图数量/旧测试计数冒充当前验收。

## 实现边界

- 页面 `#0B0C0D`，卡片 `#151719`，输入／次级表面 `#202326`，分隔 `#34383D`；主文字 `#F7F8F3`，辅助文字约 `#B4BABF`，增强对比度下提亮辅助文字。
- Volt `#C4FF00` 用于主操作、当前选择与数据进度，反色文字 `#0B0C0D`；禁用按钮保持中性。心率／失败 `#FF8C98`，警告 `#F2C66D`，蓝／紫／绿色仅用于必须区分的指标和真实图表类别。
- 复用可缩放的 SF 默认系统字体角色：Display 60、Hero 52、Metric 32、Compact Metric 22、Page Title 28、Section 17、Label 12pt。数字保留 `monospacedDigit`；这些是基础尺度，不要求每页所有指标都升为大字。
- 教练原有 76pt 数字环保留尺寸；环内两项文字使用单行比例适配避免可访问性字号下截断，VoiceOver 的原 label/value 保持完整。赛事总周期按开始日到比赛日的七日分桶计算（含比赛日），与服务端 `elapsedWeeks + 1` 一致；体能计划沿用设置值，旧配置默认 12 周。
- 教练日卡默认宽 116pt、最小高 140pt；宽度与图标高度随 Dynamic Type 缩放，宽度最多 260pt，日期／课型／距离允许完整换行，高度随内容扩展，不缩小正文或固定裁切。
- 间距、控件尺寸、模块顺序、网格、导航和原大字号 reflow 保持不变。首轮仍为水平 20、垂直 16、分区 16、面板内边距 16、页尾 24、连续圆角 8pt、零阴影；图标触控区 44×44、主按钮至少 50、Tab 至少 48、配对摘要内部 112、地图 220pt。
- 原生高清 SF Symbols、连续进度环与胶囊进度条；装饰占位保留，以中性静态图形降低插画感。不加入 Nike 标志、专属品牌资产、像素绘制、玻璃、发光、持续动画或皮肤选择器。
- 头部装饰仍只允许用页底色自身的 alpha 渐隐融入页面；`check-fresh-skin.py` 保留三块覆盖和颜色白名单判据。皮肤其余部分不得出现渐变填充的表面。
- 图表继续使用真实观测值、原比例／单位／轴方向与既有点选，不量化数据、改写路线或补造分数。互动与分享高德底图使用已安装 SDK 的 `standardNight`；离线轨迹为深色，路线／起点为 Volt，终点保持独立颜色。坐标、地图锁定、归因与隐私检查不变。
- App、导航栏、系统 Form／Sheet 和组合分享图统一深色；不是仅把背景涂黑。分享仍为同一张真实路线＋摘要组合图片。
- 地图隐私选择保留系统控件与系统表面；“同意并启用地图”显式使用行动色填充与反色文字，不继承系统白字到 Volt 背景。
- 五个原生入口复用NativeRootView、NativeAppModel、现有API与导航；不复制评分、同步或写命令逻辑。
- 展示层不能把null补成健康/0，也不能把“无今天恢复覆盖”改成“能力下降”。
- 今日能力卡/详情、计划草稿、锁课、反馈、数据状态和同步失败使用合同明确的状态及操作。
- 旧皮肤运行时样式已替换，残留UserDefaults皮肤键无人读取，不迁移或删除用户数据。
- 不新增手机实时录跑、定位、Profile、指标或训练类型；教练的暂停／继续／结束继续操作计划，不改成录跑控制。

## 数据与可访问性

同一指标的单位/精度一致；解释区分训练截至、最近样本、同步结果和响应生成时间。
缺目标、无数据、网络失败、已保存但分析中/失败分别有明确呈现，操作与说明不能相互矛盾。
大字体、VoiceOver、减少动态效果、触控区与长文换行需要真实验收，不只检查截图。
地图SDK必须经过隐私同意；未同意时仍可显示离线路线信息。坐标显示转换不能写回原始轨迹。

## 验收边界

先跑`npm run test:ios`，再按[runbook](../../../docs/IOS_NATIVE_RUNBOOK.md)执行需要设备/模拟器的步骤。
自动对比度/布局/DTO覆盖测试不等于真机朗读、帧率、耗电、后台唤醒或HealthKit权限已验收。
旧浅色外观断言已迁移为深色／夜间地图合同；尺寸、触控、数据、业务、地图手势及隐私断言不降低。对比度仍以 4.5:1 为项目文字目标，检查增强对比度、透明叠加、主按钮、破坏性确认与禁用文字。
每个主要页面需在当前构建、隔离数据库下检查默认与可访问性字号、原流程和全部状态；未启动模拟器时只可报告编译／源码门禁，不得声称截图、导航或真机性能已验收。
原始轨迹在未配置令牌时默认隐藏；仅需要验证真实离线轨迹的**本机隔离验收进程**可显式使用已有的 `RAI_API_HOST=127.0.0.1 RAI_ALLOW_ANONYMOUS_ROUTES=1` 配置。不能把此选项写入生产启动配置，也不能用列表 `hasRoute` 元数据冒充已返回坐标。高德底图／分享仍需原地图隐私同意与相应凭证，不因验收绕过。
新截图注明构建、设备、数据来源及状态，不保存个人Token、健康原始值或精确位置作为公开设计稿。
