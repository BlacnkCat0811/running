# 科技皮肤整体优化 · 2026-09-16

## 范围与原则

本轮只实现 iOS 冰蓝科技皮肤及其原生验收。保留开始工作时已有的未提交业务改动；不改 Web、评分核心、API 契约、健康只读权限、后台同步能力或像素皮肤的组件。`NativeRootView` 的必要改动仅改变科技皮肤的底栏布局分支。

风格目标为克制的运动仪表盘：深蓝底、青蓝重点、数据先于装饰。无需图片资产或新增依赖。

## 实施清单

| 方向 | 实施 |
| --- | --- |
| 视觉令牌 | 页面边距 20pt，模块间距/卡片内边距 16pt，卡片圆角 12pt；背景/卡片/重点面板三级明度；辅助文本提高明度并响应提高对比度；移除普通卡片重复渐变层。 |
| 字体 | 新增相对文本样式缩放的展示字体；关键指标不再缩小到 50%–70% 强行塞入；指标网格随宽度和字号调整列数，辅助功能字号单列。 |
| 图标与动效 | 通用功能图标统一 medium 光学重量；保留首页主仪表，训练判定用语义盾牌替代重复仪表；按压 160ms、进度变化 220ms，减少动态效果时关闭这些动画，不增加持续动画。 |
| 首页 | 判定与推荐先于完成量；推荐可直达训练计划；保留跑力、荣耀指标、周结构与身体详情；状态与训练事实不混淆。 |
| 同步 | 取消优先于历史成功，恢复的历史不标作本次成功；首页独立观察同步阶段，展示真实忙碌/错误/成功；错误原因可展开、显式重试；数据过期入口不重复错误卡的重试按钮；说明下拉刷新不等于健康导入。 |
| 安全区域 | 科技分支用真实 VStack 空间保留底栏，并裁切导航视口。页面末尾仅保留 24pt 呼吸空间，不再用固定 90pt 模拟底栏高度。初次截图发现外层 safeAreaInset 没有可靠传递到滚动目的页，修复根布局而非掩盖问题。 |
| 返回与键盘 | 深色导航使用明确可见的返回图标，并用局部、可恢复的手势委托保留系统边缘返回（不做全局 swizzle）；表单保留交互式收键盘，增加数字键盘完成操作；首次连接支持字段焦点流转；计划编辑/取消后回到首个字段/总览，不保留旧长页的深处偏移。 |
| 计划与弹层 | 周日程按空间换行，不将七个可点项挤成小于 44pt 的列；大字号的指标/处方行改为纵向；确认和锁课弹层可拖动，大字号默认大弹层；锁课请求中阻止误关闭。 |
| 今日详情加载 | 移除 `.id(generatedAt)` 强制重建，用请求版本刷新已有卡片；同一训练更新保留已加载内容，不同训练/服务不复用旧详情；失败可局部重试。 |
| 时序性能 | 科技皮肤独立图表输入等价边界；清理非有限/负时间、按时间排序、重复时刻保留最后收到值；按桶保留峰谷与端点，最多 360 绘制点。原始样本/评分不变，平均心率仍用 API 值。 |
| 图表交互 | 点击查看实际显示采样点、上一点/下一点的可点替代操作；不拦截纵向拖动；提供范围、样本数和选中值的可访问摘要。趋势图最多 240 点，量程预计算避免逐点重复扫描。 |
| 路线性能 | 相同路线避免重建派生坐标/边界；地图转换只发生在坐标变化时，地图绘制回调合并到下一轮主队列；默认立即显示真实离线轨迹，用户显式加载互动底图，隐私门控不变；离开时停止地图回调。 |
| 其他渲染 | 公里分段最大配速每面板计算一次；流式徽标布局复用相同宽度的测量结果；不对所有页面盲目替换成惰性容器。 |
| 可访问性 | 关键触控区至少 44pt；大字号真实重排、重要图表语音摘要、装饰隐藏、缺值仍为 `--`；状态不单靠颜色，预期/诊断/快照日期继续明确。底栏保留原有文字放大上限与大内容查看器，避免五入口在辅助功能字号下溢出。 |

## 回归入口

```sh
bash apps/ios/tests/typecheck-ios.sh
bash apps/ios/tests/run-tech-presentation-tests.sh
bash apps/ios/tests/run-model-tests.sh
RAI_VISUAL_DERIVED_DATA=/tmp/rai-tech-ui-build bash apps/ios/tests/run-visual-tests.sh
```

原生 UI 测试新增：系统边缘返回完成与取消、显式返回按钮、底栏上方末尾入口可达、辅助功能大字号跑力/计划、数字键盘关闭、时序点检与纵向滚动、滚动性能基线。测试使用独立 SQLite 副本、隔离 API、专用模拟器；不写生产数据、不授予健康权限、不加载高德瓦片。

`RAI_VISUAL_DEVICE` 可指定不同专用模拟器，`RAI_VISUAL_OUTPUT` 指定结果目录。`RAI_VISUAL_STARTUP_TIMEOUT` 默认 300 秒：隔离库启动验证可能超过旧的 40 秒；进程提前退出仍立即失败，不跳过验证。`RAI_VISUAL_DERIVED_DATA` / `RAI_VISUAL_TEST_DERIVED_DATA` 分别复用 App 与测试构建缓存。

已经完成的纯展示回归：41 条断言，覆盖空/单点/非法值/乱序/重复时刻/峰谷/端点/绘制上限/不修改输入、取消/失败/忙碌/历史成功的显示优先级，以及判定图标对未知 tone 的失败关闭。该脚本此前用 `-O` 编译，现已去掉：`-O` 下 `precondition` 同样会失败（EXIT 132），但断言名被吞成 `Illegal instruction: 4`，排障时得重新编一遍才知道挂的是哪条。因此下面这个微基准数字来自**优化构建的最后一轮**，与当前脚本打印的非优化数字不可直接比较：50,000 点的整理与抽样平均 4.64ms/次（10 次）；这是主机算法测量，不是 iPhone 帧率，也不是优化前后真机对比。额外直接解析生产颜色令牌的 24 组前景/背景配色通过项目设定的 4.5:1 对比度目标（含按钮与徽章——文字压在填充色上、半透明填充按叠加后的结果计算，两组 token 均从源码提取，源码改名会导致断言报错而不是静默跳过）；令牌测试不等于所有渲染页面的可访问性审计。

模拟器 Debug 的滚动基线已采集（`test14ScrollPerformanceBaseline`，14 项全量回归那一轮的数值）：

| 指标 | 三次测量的平均 | 相对标准差 |
| --- | --- | --- |
| 进程 CPU 时间 | 2.148 s | 1.36% |
| 整轮时钟时间（含 XCTest 驱动开销） | 10.480 s | 3.44% |
| 物理内存（绝对值） | 56.26 MB | 0.05% |
| 物理内存峰值 | 56.59 MB | 0.11% |
| 滚动减速 signpost 时长 | 2.310 s | 0.36% |

每个迭代为两次上滑加两次下滑。该组数字不是输入响应延迟、不是 FPS 或掉帧比率，也不是优化前后的提升比例；“整轮时钟时间”包含 XCTest 合成事件的固定开销，不能读作滚动流畅度本身。更早一轮在主机同时构建时采集到的整轮时间为 11.082 s，说明主机负载会显著影响该指标，因此只作为后续受控实测的起点。

## 跨机型复现

本轮使用了三台专用模拟器，均不改动生产数据库：

| 用途 | 设备 | 复现命令 |
| --- | --- | --- |
| 主回归（iPhone 12 Pro Max，428×926pt） | `RAI Technology Acceptance` | `RAI_VISUAL_DEVICE=<udid> bash apps/ios/tests/run-visual-tests.sh` |
| 小屏 + 提高对比度（iPhone SE 3，375×667pt） | `RAI Tech Small Acceptance` | 同上，另用 `xcrun simctl ui <udid> increase_contrast enabled` |
| 灵动岛（iPhone 17 Pro Max，440×956pt） | `RAI Tech Island Acceptance` | 同上 |

后两台是本轮创建的本地模拟器；不再需要时可用 `xcrun simctl delete <udid>` 删除（仅影响本地模拟器，不涉及仓库或用户数据）。单台模拟器顺序执行可避免同时启动多台导致的 AX 初始化超时。

## 真机验收边界

模拟器截图/测试与主机微基准不代替真机 Instruments。正式性能验收需在同一台 iPhone、同一数据集、同一电源/温度条件下比较 Release 版本：冷/热启动、首页连续滚动、长训练详情、加载互动地图、前台健康同步期间操作。观察主线程长任务、滚动 hitch、CPU/峰值内存，并实际使用 VoiceOver 和减少动态效果设置。

不承诺未经测量的 FPS 提升比例、无掉帧、续航收益或所有机型完成验收。不得把模拟器健康授权失败当作产品成功状态，也不为截图伪造测量值或进度。
