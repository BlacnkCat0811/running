## 数据与边界

使用本机数据库的独立 SQLite 副本，所有服务运行在 loopback 测试端口。真实数据最新到 2026-08-25，因此首页可能显示零次训练、过期数据和缺失恢复证据；不复制设计稿的 8.42 km、82%、示例日期和虚构后台进度。

逐日计划只在独立副本中，用 API 自己给出的七日建议填充空编辑器。路线上真实道路、距离、时序和分区均来自现有 API。

异常截图由 `visual-state-proxy.py` 注入断网、空列表和延迟；同步失败在握手阶段触发，未授予健康权限。`03-lock-preview-fixture` 仅放开测试响应中的过期标志以查看锁课面板，代理禁止所有业务写入；不能据此证明真实锁课成功。

## 验收判定口径

构建通过、流程断言和人工视觉比对分别记录，不用截图数量代替“通过”。AI 概念图存在小字失真、数据样例和互相不同的设备/图表样式，不能合理声明与其逐像素相同。

## 重现

在 Mac 上准备独立模拟器 `RAI Technology Acceptance`，保持 8792–8794 端口空闲，从仓库根目录运行：

```sh
bash apps/ios/tests/run-visual-tests.sh
bash apps/ios/tests/run-model-tests.sh
```

脚本自动复制数据库并启动隔离 API/只读故障代理，生成 Xcode 结果包和带名字的原生截图。可设置 `RAI_VISUAL_DEVICE`、`RAI_VISUAL_DATABASE`、`RAI_VISUAL_OUTPUT`。不要把测试端口指向生产服务。
